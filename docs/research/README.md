## 変換の範囲

本文、数値、検証上の留保、表のセル、図の説明、外部出典URLは原本のままです。実験やTAS再生の再検証は行っていません。

原本の同一ページを指すWindowsの絶対パス18件を、`#summary` などのページ内リンクに置換しました。埋め込みPNG画像2枚は再圧縮せず抽出し、CSSとともに相対パスで参照しています。HTML版の概念図3点は元のインラインSVGを保持しています。

Markdown版では、GitHubで表示できるよう概念図を独立したSVGファイルに抽出しました。SVGにXML名前空間を追加した以外は図の内容を変更していません。元の図のタイトルと説明を代替テキストに使用しています。表5点をMarkdownの表に変換し、表題・図注も保持しました。目次・本文内参照・先頭へのリンクには明示的なアンカーを用いています。

GitHub Pagesの設定変更や公開は行っていません。HTML版の閲覧には、HTMLだけでなく `assets/` もダウンロードしてください。

## 再生成・確認

Python 3とPandoc 3.xが必要です。変換時に使用したPandocは3.1.3です。

```sh
python3 scripts/convert_research_report.py
python3 scripts/verify_research_report.py
```

確認スクリプトは、HTML版およびMarkdownから再構成したHTMLについて、空白・改行を除く本文テキストの一致、全27リンクの保持、18件の内部リンク先の存在、表5点・データセル65個・見出しセル16個、相対参照ファイルの存在を確認します。PNGは原本の画像バイト列と完全一致、SVGは名前空間追加以外の一致を確認します。外部サイトの継続的な可用性を保証するものではありません。
