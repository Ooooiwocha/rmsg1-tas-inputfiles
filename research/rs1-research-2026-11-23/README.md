# ロマサガ1 レイディバグ 研究データ（2026-11-23 時点）

実行環境が入れ替わっても続きができるように、道具（C#）と実験結果をまとめたものです。

## 環境の作り直し

- BizHawk 2.11.1（Linux版）を展開し、`mono`（apt）を入れる。
- ROM：`rs1.sfc`（日本版SFC、sha256 2542de1b…）を `/home/claude/work/rs1.sfc` に置く。
- TAS入力：`latest/RS1_BizHawk_tail_search_x_7279F_verified.bk2` を `/home/claude/work/bk2_7279/` に展開（`Input Log.txt` を使う）。
- コンパイル（BizHawkのフォルダを `$BH` として）：
  `mcs -unsafe -out:$BH/X.exe -r:$BH/dll/BizHawk.Emulation.Common.dll -r:$BH/dll/BizHawk.Emulation.Cores.dll -r:$BH/dll/BizHawk.Common.dll [-r:System.IO.Compression.dll] H.cs X.cs`
- 実行：`cd $BH; export LD_LIBRARY_PATH=$PWD/dll:$PWD MONO_PATH=$PWD/dll; mono X.exe ...`

## 分かっていること（要点）

- 7章の入口のうち、7,279Fを切るのに関係するボタン待ちは同じバンクで少し上にある20か所だけ（各々「この時刻までに止まれば間に合う」が決まる）。$1B:C275（7,264F、TAS）、$1B:B6B1（7,272F）、$1A:C255（7,273F）、$1B:BB7E（7,269F）、$1A:CB56（7,262F）、$1B:C47F（7,260F）、$1B:C77E（7,257F）、$1B:D5BC（7,244F）、$1B:D8BB（7,241F）、$1B:DCB1（7,234F）ほか。
- 次の予定：この20か所に絞って「期限までに12枚目のメモで止まれるか」を調べる。状態はメモリでなくディスクに置く。
- アイアンロックの行き先番号は 0x0277（バーバラ編エンディングのスクリプト）。地名表示は変数0x12のビット2。
